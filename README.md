# Online Student Feedback System (MERN prototype)
Prereqs: Node 18+, MongoDB running locally (or set MONGO_URI).

Backend:  cd backend && npm install && npm start      (http://localhost:5000)
Frontend: cd frontend && npm install && npm run dev   (http://localhost:5173)

Demo admin: admin@dsce.edu / admin123  (seeded automatically, with 3 sample courses)
Students register from the login page.
